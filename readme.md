# DevOps Dashboard ⚙️

A simple and professional **DevOps Dashboard** built with **HTML, CSS, and JavaScript**.  
This project is created for practice and deployment on **Vercel**.

## 🚀 Features
- Real‑time system health simulation (CPU, Memory, Disk usage)
- Deployment status section with build states
- Auto‑updating logs with timestamps
- Alerts section for simulated warnings
- Responsive grid layout for desktop and mobile
